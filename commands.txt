1. SCP(Secure Copy Protocol):-
The scp (Secure Copy Protocol) command is used to securely transfer files and directories between systems over a network.
scp (Secure Copy Protocol) is a Linux/Unix command used to securely copy files and directories between computers over SSH.
It works over SSH, which means all transferred data is encrypted. 
It is commonly used by system administrators to move backup files, fetch logs, copy configuration files, and transfer data between servers safely and quickly.
syntax:- scp [file_name]  remoteuser@remotehost:/remote/directory

To copy a file from a remote machine to your local system, you just reverse the source and destination
syntax: scp user@remotehost:/home/user/file_name .

2. DISK:-
disk refers to a physical or virtual storage device used to store data permanently.
A disk can be divided into partitions, which are smaller sections of the disk.
df -h-------------> display the amount of storage, used storage left storage.
du -sh <folder>----------->displays the amount of storage/disk used by that folder
Alerting script
df -h | awk '$5+0 > 80 {print "ALERT: Disk usage above 80% on", $6}'

4. SERVICE MANAGEMNT:-
Services are the process that will be executed in the background and they start running at the boot of the system.
systemctl list-units --type=service:- lists all the services that are running
systemctl stop <service-name>:- to stop the a service
systemctl start <service-name>:- to start the service

6. Find command:- https://www.geeksforgeeks.org/linux-unix/find-command-in-linux-with-examples/
The find command in Linux is used to search for files and directories based on name, type, size, date, or other conditions. It scans the specified directory and its sub directories to locate files matching the given criteria.
eg:- find ./GFG -name *.txt 
find ./GFG -perm 664
find . -type d
find /path/to/search -mtime -7
find / -type f -size +100M  

NOTE:- +7:- more than 7 days, -7:- less than 7 days
